## Tools

The model-facing surface: each tool the minimal
composition mounts, with the parameters and description the
model reads (`:tools` registration order).

### `read`

**Label:** Read file

**Parameters:** `path` (required), `offset`, `limit`

**Description:**

Read the contents of a file. Supports text files and images (jpg, png, gif, webp, bmp). Images are sent as attachments. For text files, output is truncated to 2000 lines or 50KB (whichever is hit first). Use offset/limit for large files. When you need the full file, continue with offset until complete.

---

### `write`

**Label:** Write file

**Parameters:** `path` (required), `content` (required)

**Description:**

Write content to a file. Creates the file if it doesn't exist, overwrites if it does. Automatically creates parent directories.

---

### `edit`

**Label:** Edit file

**Parameters:** `path` (required), `edits` (required)

**Description:**

Edit a single file using exact text replacement. Every edits[].oldText must match a unique, non-overlapping region of the original file. If two changes affect the same block or nearby lines, merge them into one edit instead of emitting overlapping edits. Do not include large unchanged regions just to connect distant changes.

---

### `bash`

**Label:** bash

**Parameters:** `command` (required), `timeout`

**Description:**

Execute a bash command in the current working directory. Returns stdout and stderr. Output is truncated to last 2000 lines or 50KB (whichever is hit first). If truncated, full output is saved to a temp file. Optionally provide a timeout in seconds.

---

### `codemode`

**Label:** Codemode

**Parameters:** `code` (required), `timeout`, `max-output-bytes`

**Description:**

Fresh Clojure SCI sandbox with the active tools bridged in; definitions do not persist.
Files: (read "p") or (read "p" {:offset N :limit N}); (write "p" text); (edit "p" old new).
Shell: (bash "cmd1 && cmd2" {:timeout N}) -> output + status; a nonzero exit is normal.
Tools: @(tools/call "name" args) settles with {:content :is-error :details :truncation :images}; @(tools/read {…}) is the per-tool shorthand, while (tools/call! …) is one call derefed, throwing when it fails; (tools/ok? r), (tools/text r) and (tools/error r) read a result. (tools/list) lists the callable tools with their descriptions and parameters; (tools/describe "name") returns one declaration. Inner results never enter the conversation.
Batch independent reads, commands, and tests into one call; (emit v) for full output. Multi-form calls report one line per form.
Example: (emit {:spec (read "SPEC-v2.txt") :tests (bash "bash test-v1.sh; bash test-v2.sh")}).
Return the final value or (emit v); println is discarded. Prefer (slurp path), (spit path text), fs/*, and (p/sh ...) for whole-file and shell work. (emit-image path) attaches an image. Output is capped at 16 KiB/2000 lines; :max-output-bytes raises it to 50 KiB.

---

### `eval`

**Label:** Eval

**Parameters:** `code` (required), `timeout`, `max-output-bytes`

**Description:**

Persistent Clojure SCI sandbox; no registered tools.
Files: (read "p") or (read "p" {:offset N :limit N}); (write "p" text); (edit "p" old new).
Shell: (bash "cmd1 && cmd2" {:timeout N}) -> output + status; a nonzero exit is normal.
Batch independent reads/tests in one call; (emit v) for full output. Multi-form calls report one line per form.
Example: (emit {:spec (read "SPEC-v2.txt") :tests (bash "bash test-v1.sh; bash test-v2.sh")}).
Definitions and results persist; return the final value or (emit v); println is discarded. Extension verbs are called as <id>/verb, e.g. (mcp/search ...). (help) for the eval library, persistence, results, and limits.

---

### `tool_search`

**Label:** Tool search

**Parameters:** `query` (required), `limit`

**Description:**

Searches over deferred tool metadata and exposes matching tools for the next model call.

Some of the tools, such as tools of MCP servers, may not have been provided to you upfront, and you should use this tool (`tool_search`) to search for the required tools. For MCP tool discovery, always use `tool_search`.

---

### `session_recall`

**Label:** Session Recall

**Parameters:** `query`, `range`, `expand`, `page`, `scope`, `mode`

**Description:**

Recall earlier parts of this session, including anything dropped by compaction.
Use it before saying the context is gone.

Pick one per call:
- query: keyword search (regex works), 5 results per page.
- range: [from, to]: entries #from..#to in order, 20 per page.
- expand: [N, ...]: full text of those entries.
- mode: 'touched': files worked on, with entry indices.
- query '#N:path': file content from entry N ('#N:path:full' for all lines).

Add to any of them: page: next page; scope: 'lineage' (default) or 'all'.
#N is the number shown in summary refs like (#12) and in recall results.
Only the current session is searchable. One result is capped at 50 KB.
